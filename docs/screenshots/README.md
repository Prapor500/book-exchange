# Скриншоты экранов

Сюда нужно положить скриншоты запущенного приложения (`npm run dev`):

- catalog.png
- book-detail.png
- bookings.png
- locations.png
- stats.png

Ориентир по внешнему виду — интерактивный превью-макет, который был показан
в чате при создании этой лабораторной работы (тот же набор экранов, та же
цветовая палитра). Реальные скриншоты нужно сделать из работающего
React-приложения после `npm install && npm run dev`.
