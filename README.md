# КнигоОбмен — обмен книгами между читателями

Frontend-приложение для проекта «Обмен книгами»: каталог книг, бронирование,
контроль сроков возврата, точки выдачи и простая статистика по фонду.

Лабораторная работа №1: интерфейс приложения и каркас frontend.

## 1. Назначение приложения и пользовательские сценарии

Приложение помогает сообществу читателей делиться бумажными книгами: находить
нужную книгу в общем фонде, бронировать её и вовремя возвращать в одну из
точек выдачи.

**Основные сценарии:**

1. **Найти книгу.** Читатель открывает каталог, ищет книгу по названию/автору
   или фильтрует по жанру, видит её статус (доступна / забронирована / на руках).
2. **Забронировать книгу.** Читатель открывает карточку книги, видит описание
   и точку выдачи, нажимает «Забронировать» и получает подтверждение со сроком,
   когда нужно её забрать.
3. **Следить за сроками возврата.** Читатель открывает «Мои бронирования» и
   видит список активных броней с датой возврата и статусом (активна /
   просрочена / возвращена).
4. **Выбрать точку выдачи.** Читатель смотрит список точек с адресом, часами
   работы и количеством книг в наличии, чтобы выбрать удобную.
5. **Оценить состояние фонда.** Администратор/читатель открывает статистику:
   сколько книг всего, сколько доступно, сколько на руках, сколько
   просрочено, и как книги распределены по жанрам и точкам выдачи.

**Экраны, которые из этого следуют:**

| Экран                        | Маршрут        | Назначение                                   |
| ----------------------------- | -------------- | --------------------------------------------- |
| Каталог книг                  | `/`            | Поиск и фильтрация книг по жанру              |
| Карточка книги / бронирование | `/books/:id`   | Детали книги, точка выдачи, кнопка «Забронировать» |
| Мои бронирования              | `/bookings`    | Таблица броней со сроками возврата и статусом |
| Точки выдачи                  | `/locations`   | Список точек с адресом, часами и наличием     |
| Статистика                    | `/stats`       | Ключевые метрики фонда и бронирований         |

## 2. Стек и структура проекта

- **React 18 + TypeScript**, сборка через **Vite**.
- **react-router-dom** — клиентская маршрутизация между экранами.
- **MUI (Material UI)** — готовая библиотека UI-компонентов (AppBar, Card,
  Table, Chip, Grid и т.д.), обеспечивает единый стиль, читаемость и базовую
  адаптивность (сетка `Grid` с брейкпоинтами `xs/sm/md`).
- Тема оформления (`src/theme.ts`) задаёт собственную цветовую и шрифтовую
  палитру в стиле бумажного библиотечного каталога (чернильно-синий,
  пергамент, тиснение цвета латуни), а не дефолтный вид MUI.

```
src/
  main.tsx            # точка входа, подключение темы и роутера
  App.tsx             # описание маршрутов
  theme.ts            # кастомная MUI-тема
  types.ts            # общие типы (Book, Booking, PickupLocation)
  data/mockData.ts    # демонстрационные данные (книги, брони, точки выдачи)
  components/
    Layout.tsx         # шапка с навигацией + Outlet
    BookCard.tsx        # карточка книги в каталоге
    StatCard.tsx         # карточка метрики в статистике
  pages/
    CatalogPage.tsx      # экран «Каталог»
    BookDetailPage.tsx   # экран «Карточка книги / бронирование»
    MyBookingsPage.tsx   # экран «Мои бронирования»
    LocationsPage.tsx    # экран «Точки выдачи»
    StatsPage.tsx        # экран «Статистика»
docs/screenshots/     # скриншоты экранов (см. ниже)
```

Данные пока демонстрационные (`src/data/mockData.ts`) — в следующих
лабораторных работах они будут заменены на запросы к backend (FastAPI).

## 3. Запуск проекта

```bash
npm install
npm run dev
```

Приложение поднимется на `http://localhost:5173`.

Продакшн-сборка:

```bash
npm run build
npm run preview
```
