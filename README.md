# КнигоОбмен — обмен книгами между читателями

Frontend-приложение для проекта «Обмен книгами»: каталог книг, бронирование, контроль сроков возврата, точки выдачи и статистика фонда.

## Назначение и пользовательские сценарии

Приложение помогает читателям находить книги в общем фонде, бронировать доступные экземпляры и выбирать удобные точки выдачи.

1. Найти книгу по названию или автору, отфильтровать каталог по жанру и посмотреть статус книги.
2. Открыть карточку книги, изучить описание и место выдачи, затем забронировать доступную книгу.
3. Посмотреть список бронирований, даты и статусы.
4. Найти точку выдачи по названию или адресу и проверить часы работы.
5. Просмотреть статистику фонда: доступность, книги на руках, просрочки, жанры и распределение по точкам.

## Стек

- React 18, TypeScript, Vite.
- React Router — клиентская маршрутизация.
- MUI (Material UI) — UI-компоненты, формы, таблицы, карточки и статусы.
- React hooks (`useState`, `useMemo`, `useSyncExternalStore`) — состояние интерфейса, фильтрация и синхронизация бронирований.
- `localStorage` — сохранение демонстрационных бронирований между перезагрузками.
- TypeScript — типизация предметных сущностей и параметров компонентов.

## Структура frontend

```text
src/
  components/
    BookCard.tsx
    Layout.tsx
    StatCard.tsx
  data/
    mockData.ts
  features/
    booking/model/bookingStore.ts
  pages/
    CatalogPage.tsx
    BookDetailPage.tsx
    MyBookingsPage.tsx
    LocationsPage.tsx
    StatsPage.tsx
  shared/ui/
    EmptyState.tsx
    PageTransition.tsx
  App.tsx
  main.tsx
  theme.ts
  types.ts
```

Структура организована по назначению: `pages` содержит страницы маршрутов, `features/booking` — логику бронирования, `components` — повторно используемые предметные компоненты, `shared/ui` — общие UI-элементы, `data` — демонстрационные данные. Это упрощённый вариант Feature-Sliced Design: строгого соблюдения всех слоёв FSD проект не требует.

## Что реализовано в лабораторной работе №3

- Каталог: поиск по названию и автору, фильтр по жанру, счётчик результатов, сброс фильтров и состояние отсутствия результатов.
- Карточка книги: состояние доступности, подтверждение бронирования, обработка неизвестного идентификатора и переход обратно в каталог.
- Бронирования: список с датами и статусами, фильтры по статусу, пустое состояние и адаптация таблицы для небольших экранов.
- Точки выдачи: поиск по названию и адресу, карточки с адресом, часами работы и количеством книг.
- Статистика: показатели фонда, распределение по жанрам и точки выдачи; счётчики учитывают бронирования, созданные в интерфейсе.
- Состояние бронирований вынесено в отдельный модуль и синхронизируется между страницами. Данные сохраняются в `localStorage`.
- Добавлены общие компоненты пустого состояния и анимации перехода между страницами, адаптивная навигация и hover-состояния карточек.
- Формы поиска имеют подписи и доступные названия; результат фильтрации объявляется через `aria-live`.

### Ограничения демонстрационной версии

Бронирования хранятся только в локальном браузере и не синхронизируются между пользователями или устройствами. Данные каталога, точек выдачи и исходных бронирований остаются демонстрационными. После интеграции backend локальное хранилище следует заменить API-запросами к FastAPI.

## Запуск

Требуется Node.js и npm.

```bash
npm install
npm run dev
```

Откройте адрес, который выведет Vite (по умолчанию `http://localhost:5173`).

Проверка TypeScript и production-сборка:

```bash
npm run build
```

Предпросмотр production-сборки:

```bash
npm run preview
```
